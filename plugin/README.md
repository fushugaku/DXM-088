# DXM-088 0.7.0 — VST3 / AU / CLAP

Инструментальный плагин с Rust DSP из прошивки LXR-02 1.71, встроенным секвенсором и локальным WebView-редактором. Один экземпляр — шесть голосов, семь дорожек, 128 паттернов до 64 шагов, основной стереовыход и семь отдельных стереовыходов.

## MIDI и выходы 0.7.0

**MIDI → Patterns**: нота запускает паттерн на время удержания. Все 128 нот доступны; при перекрытии последняя нота имеет приоритет. Это режим по умолчанию, в том числе для старых проектов.

**MIDI → Drums**: каждая Note On запускает один удар, velocity задаёт силу. Длина MIDI-ноты не обрывает затухание. Встроенный секвенсор сам не запускается; Play позволяет отдельно прослушать паттерн. Семь полей MIDI под переключателями задают раскладку, которая сохраняется в проекте и доступна автоматизации. По умолчанию: Drum 1 — **36**, Drum 2 — **45**, Drum 3 — **47**, Snare — **38**, Cymbal — **49**, Closed Hat — **42**, Open Hat — **46**. Можно назначить одну ноту нескольким инструментам для слоя. Закрытый и открытый хэт сохраняют общий choke.

Экспорт **Drum notes** использует эту же раскладку, чтобы MIDI можно было вернуть в DXM-088 в режиме Drums. Высота отдельного шага сохраняется во внутреннем паттерне и WAV; в MIDI-экспорте нота обозначает инструмент.

**Output → Mix**: весь инструмент идёт в основной стереовыход Mix с общей мастер-обработкой. Семь дополнительных выходов молчат.

**Output → Separate**: каждая дорожка идёт в свою стереопару — Drum 1, Drum 2, Drum 3, Snare, Cymbal, Closed Hat, Open Hat. Основной Mix молчит. Сохраняются синтез, эффекты голоса, WAV-слой, уровень, pan, mute/solo и Master gain. Общая секция master FX в отдельные выходы не поступает. Режим работает и с паттернами, и с прямыми ударами.

### Раздельные дорожки в Ableton Live

1. Загрузить DXM-088 на MIDI-дорожку и выбрать **Output → Separate**.
2. Создать семь Audio-дорожек. В верхнем **Audio From** каждой выбрать MIDI-дорожку с DXM-088, в нижнем — нужный выход плагина, например **Snare** или **Closed Hat**.
3. Включить **Monitor → In** на принимающих дорожках. Эффекты и запись аудио настраиваются для каждой дорожки отдельно.

Описание маршрутизации: [Using multi-out plug-ins — Ableton](https://help.ableton.com/hc/en-us/articles/209773065-Using-multi-out-plug-ins). Плагин также поддерживает обычную конфигурацию с одним стереовыходом; для Separate хост должен подключить дополнительные выходы.

Ручки сохраняют исправления 0.3.1: относительное вертикальное перетаскивание, плавное переключение точности с Shift, прокрутка с учётом движения трекпада и защита от устаревших ответов хоста. Автоматизация обновляет существующие элементы редактора, сохраняя захват указателя. Списки параметров открываются поверх окна редактора шага, помещаются в видимую область и прокручиваются отдельно; работают стрелки, Home/End и поиск набором текста.

## Возможности 0.4.0

- У каждой из семи дорожек собственное деление: 1/1, 1/2, 1/4, 1/8, 1/16, 1/32, 1/64, четыре триольных и два пунктирных значения. **STEP** меняет длительность шага, **LENGTH** — длину цикла 1–64, **HITS** — число равномерно распределённых ударов. HITS сохраняет настройки нот, условия, microtiming и parameter locks; можно также расставлять удары вручную. Все три настройки независимы для каждого паттерна.
- **Timing**: сдвиг дорожки ±49% шага, Swing / Broken / Push / Laid back с регулируемой глубиной. У шага есть собственный microtiming ±49%, вероятность, ratchet и два parameter lock. Редактор шага открывается справа; параметры ищутся по имени и группе.
- Условия шагов: Always, First pass, After first pass, Fill, Not Fill, Previous hit, Previous missed, Every N passes. Последний режим задаёт цикл 1–16 проходов и номер прохода. Цикл считается отдельно от длины каждой дорожки; первый проход начинается при старте/перемотке или смене паттерна.
- **Perform**: четыре макроса с переименованием двойным щелчком по имени. Velocity удерживаемой MIDI-ноты задаёт общую интенсивность через Velocity influence. Поддерживаются channel/poly aftertouch, CC1 и моментальный Fill на CC64. Переключение паттерна — сразу, на следующей 1/16 или на следующем такте 4/4; отпускание всех нот останавливает секвенсор сразу.
- **Scenes**: Capture sound + mix сохраняет синтез, FX, микшер, morph и макросы для выбранного паттерна. MIDI-нота выбирает паттерн вместе с его сценой. Use shared sound возвращает паттерн к общим настройкам. Сохранённые сцены независимы; общие настройки отражают последние ручные изменения.
- **Matrix**: 16 назначений из четырёх макросов, velocity, aftertouch, mod wheel и двух LFO в темпе на любой из 39 параметров шести голосов. Глубина каждого назначения от −100% до +100%. Модуляция складывается в нормализованной шкале; параметры с логарифмической шкалой сохраняют её.
- **Sample**: свой WAV на каждую дорожку, включая отдельные слои закрытого и открытого хэта с choke. Mono/stereo PCM 8/16/24/32 и float32, до 10 секунд и 960 000 кадров. Стереофайл сводится в mono; в проект встраивается PCM16. Доступны уровень, высота, start/end, decay, Synth + sample / Sample only. Слои общие для всех сцен.
- **Mutate**: глубина изменения тембра, защищённые параметры и Revert. По умолчанию защищены высота, основные времена и уровни; доступен обычный Undo.
- **Export**: стерео WAV 44.1 kHz / PCM16 с хвостом 2 секунды, MIDI с семью барабанными дорожками или Pattern gate — удерживаемая нота для запуска DXM-088. Семь WAV-stems сохраняются ZIP-файлом. После подготовки файлы можно перетащить из нативного macOS-редактора в DAW. Сохранение также доступно через системный диалог. В браузере возможности внешнего drag зависят от браузера; Save file работает отдельно. Максимальная длительность аудиорендера — 120 секунд. Такт экспорта/квантизации — четыре четверти.

Проекты имеют версию **4**. Старые v1/v2/v3 загружаются с прежними ритмами и настройками; новые функции по умолчанию нейтральны. WAV-слои хранятся внутри проекта DAW / JSON, в браузере автосохранение использует IndexedDB. Демонстрационный проект `Examples/Polyrhythm Scenes.dxm088.json` (в рабочей папке: `examples/Polyrhythm Scenes.dxm088.json`) показывает независимые циклы, восемь сцен и MIDI-модуляцию.

## Исправления 0.6.1

- Обновлена обработка фокуса и клавиатуры macOS WebView. Length/Hits сохраняют ввод при перерисовке сетки и получили кнопки ±; клавиши A S D F G H J используют физические позиции и работают при смене раскладки.
- Play / Space запускает предпрослушивание текущего паттерна без MIDI. Удерживаемые MIDI-ноты имеют приоритет; отпускание последней останавливает секвенсор. Предпрослушивание не сохраняется как автоматический запуск в проектах.
- VST3 объявляет все 16 MIDI-каналов, включая aftertouch, CC1 и Fill CC64.

## Банк 0.6.0

128 независимых паттернов и сцен в 16 банках по 8. В старых проектах сохраняется прежнее начало MIDI-раскладки (обычно нота 24), поэтому записанные клипы продолжают выбирать A01–A08 на тех же нотах. Новые слоты заполняются независимыми копиями исходных восьми паттернов и сцен. Изменение одной копии не меняет остальные. Экспорт Pattern gate использует точную MIDI-ноту текущего паттерна, включая циклическую раскладку.

## Переименование 0.5.0

Имя инструмента — **DXM-088**. Числовые ID AU/VST3, строковый ID CLAP, ID параметров и формат состояния сохранены. Старые JSON-проекты открываются. При обновлении замените прежний LXR02 соответствующего формата: два файла с одинаковой идентичностью могут конфликтовать при сканировании DAW. Внутренние имена crate и C ABI остались прежними.

## Использование режима Patterns

1. Добавить **DXM-088** на инструментальную MIDI-дорожку.
2. Нарисовать длинную MIDI-ноту **0 (C−2)**. В новом проекте она запускает **A01**, пока удерживается.
3. Все ноты **0–127 (C−2–G8)** запускают отдельные паттерны: **0 → A01, 7 → A08, 8 → B01, 127 → P08**. Банки **A–P** переключаются списком слева от восьми кнопок; при MIDI-воспроизведении банк меняется автоматически. Поле **A01** / параметр **A01 MIDI note** задаёт начало раскладки с циклическим переходом через 127, сохраняя доступ ко всем 128 слотам. Названия октав в разных DAW могут отличаться.
4. Перекрывающиеся ноты: последняя нажатая имеет приоритет, её отпускание возвращает предыдущую удерживаемую. Отпускание всех нот закрывает секвенсор; затухание голосов и эффектов продолжается.
5. Сохранить проект DAW. Он хранит все параметры, 128 паттернов, длины дорожек, вероятность, ratchet, ноты, оба parameter lock на каждом шаге и MIDI-диапазон. Через **Session** можно обмениваться файлами с браузерной версией; экспорт открывает системный диалог сохранения.

При включённом транспорте шаги следуют абсолютной сетке PPQ DAW, включая swing, изменение темпа, перемотку и петли. Смена паттерна применяется по настройке Pattern change; по умолчанию сразу к текущему шагу сетки каждой дорожки. Удерживаемая нота также запускает секвенсор при остановленном транспорте, с последним темпом хоста и с первого шага. Остановка DAW сбрасывает удержанные ноты. CC 123 освобождает ноты канала, CC 120 также очищает звук. Каждая MIDI-нота выбирает паттерн; барабаны не транспонируются.

Кнопки паттернов выбирают редактируемый паттерн, когда нет удерживаемой ноты. Во время MIDI-воспроизведения редактор следует активному паттерну. Пэды Trigger позволяют прослушивать отдельные голоса. Play / Space запускает предпрослушивание; удерживаемая MIDI-нота перехватывает управление. Темп сообщает хост, swing редактируется в плагине.

## Готовые файлы и установка

macOS 11+, **Apple Silicon и Intel в одном бинарном файле**:

- `build/plugins/dxm088-macos-universal/DXM-088.vst3`
- `build/plugins/dxm088-macos-universal/DXM-088.component` — Audio Unit v2, тип `aumu`
- `build/plugins/dxm088-macos-universal/DXM-088.clap`
- `build/plugins/DXM-088-macOS-universal.zip`
- `build/plugins/DXM-088-0.7.0-macOS-universal.pkg` — установщик с выбором VST3, AU и CLAP.

Открыть `.pkg` и пройти установку. Пакет устанавливается для текущего пользователя без пароля администратора, в `~/Library/Audio/Plug-Ins/VST3`, `Components` и `CLAP`. Документация и лицензии находятся в `~/Library/Application Support/DXM-088`. Перед обновлением закрыть экземпляры DXM-088 в DAW. Установщик не подписан Developer ID Installer и не нотариализован.

Установка в папку текущего пользователя:

```sh
./tools/install-plugins.sh
```

Скрипт кладёт пакеты в `~/Library/Audio/Plug-Ins/VST3`, `Components` и `CLAP`. После установки выполнить повторное сканирование в DAW; при необходимости перезапустить её. Это локальная ad-hoc подпись, без Developer ID и нотариализации Apple.

Windows x64: VST3 и CLAP собираются командой `tools/build-plugins.ps1`, также доступна сборка через GitHub Actions. ZIP содержит `Install.cmd` для установки в папки текущего пользователя. Папка `DXM-088.resources` должна находиться рядом с `DXM-088.clap`. Нужны Visual Studio Build Tools с C++, Windows SDK, CMake, Rust stable, Node/npm и Python. Редактор использует WebView2. Сборка проверяет PE x64, наличие ресурсов и загрузку CLAP; проверка в Windows DAW отдельно не выполнялась. AU доступен на macOS. Linux-оболочка в этой версии не реализована.

## Сборка и проверка

```sh
./tools/build-plugins.sh
./tools/install-plugins.sh
./tools/verify-plugins.sh
auval -v aumu LxR2 ErRs
```

Сборка плагинов также создаёт `.pkg`. Повторная упаковка готовых универсальных бинарных файлов: `python3 tools/build-installer.py`. Упаковщик проверяет архитектуры, подписи плагинов, контрольные суммы всех файлов после распаковки, папку установки и независимый выбор форматов. Отчёт: `artifacts/installer-verification.json`.

Скрипт сборки получает SDK по закреплённым коммитам из `plugin/SOURCES.json`; DSP остаётся в существующем Rust crate. WebView работает из ресурсов пакета с встроенным WASM для модели редактора, без HTTP-сервера и внешних страниц. Звук DAW вычисляет нативный Rust, WASM в редакторе не воспроизводит звук.

- 283 параметра автоматизации: прежние 274 ID сохранены, добавлены четыре макроса, velocity influence, Fill, квантизация переключения и два периода LFO.
- MIDI-события применяются с точностью до сэмпла внутри блока. Темп и положение читаются из контекста обработки хоста.
- Аудиопоток не берёт mutex, не разбирает JSON и не выделяет память. Короткие команды поступают через фиксированную очередь; импорт проекта создаёт готовый экземпляр вне аудиопотока. Удаление заменённых экземпляров отложено до UI-потока. Замена данных проекта сохраняет удержанные ноты, положение транспорта и живое состояние DSP без выделения памяти в аудиопотоке.
- CLAP принимает MIDI 1.0; запись/чтение состояния поддерживает частичные операции потока и сообщает хосту об изменении значений после восстановления.
- Параметры в редактор передаются JSON в физических единицах, чтобы не терять точность через строковое форматирование нормализованных значений SDK.
- Нативные тестовые хосты проверяют частоты 44,1 / 48 / 96 / 192 кГц у всех трёх форматов с тем же Rust-движком. Проверяются MIDI offsets, темп, перемотка, остановка, переменный размер блока, latency и восстановление состояния.

Проверка Logic Pro и новая сверка с аппаратным LXR-02 для 0.4.0 не выполнялись по запросу пользователя.

Скрипты воспроизводимых проверок находятся в `tools/`; локальные отчёты и проекты DAW не публикуются.

## Исходники

- `plugin/engine` — Rust: экземпляры движка, MIDI-gate, приоритет нот, PPQ-clock, состояние и C ABI.
- `plugin/LXR02.cpp` — iPlug2: VST3/AU/CLAP, параметры, очередь команд, сохранение и WebView.
- `web/app.js`, `web/plugin-bridge.js` — общий редактор браузера и плагина.
- `tools/package-plugin-ui.py` — локальная упаковка ресурсов.
- `plugin/tests/editor_host.mm` — отдельный Cocoa-хост для визуальной проверки CLAP без звукового устройства.

Оболочки используют [iPlug2](https://github.com/iPlug2/iPlug2), [Steinberg VST3 SDK](https://github.com/steinbergmedia/vst3sdk) и [CLAP](https://github.com/free-audio/clap). Происхождение DSP и ROM описано в [NOTICE.md](../NOTICE.md). Фирменные знаки принадлежат владельцам.
